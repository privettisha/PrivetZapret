# PrivetZapret

Локальное приложение для выбранных сервисов на Windows 10/11 и Arch Linux. Устанавливается одной кнопкой, запускается вместе с системой и не отправляет весь интернет через сторонний сервер.

## Windows 10/11

1. Скачайте `PrivetZapret-Windows-x64.exe`.
2. Запустите файл и подтвердите запрос Windows.
3. Нажмите «Установить».

После установки программу можно закрыть — системная служба продолжит работать. Удаление доступно в том же окне.

Для Telegram нажмите «Подключить в Telegram» и подтвердите добавление локального прокси. Программа поднимает его только на `127.0.0.1`, поэтому подключиться к нему извне нельзя.

Начиная с версии 0.2 WinDivert хранится в отдельной версионной папке: обновление не пытается перезаписать уже загруженный драйвер. Поэтому повторная установка работает даже когда Windows удерживает `WinDivert64.sys` в ядре и в диспетчере задач нет связанного процесса.

## Arch Linux

Нужны `nftables` и `systemd`:

```bash
sudo pacman -S nftables
chmod +x PrivetZapret-Arch-x64
sudo ./PrivetZapret-Arch-x64
```

Откроется локальная страница управления. После установки сервис будет запускаться автоматически.

В приложении можно отдельно выбрать YouTube, Discord, Telegram Desktop и сервисы из каталога социальных сетей, видео и сообществ. Есть поиск, быстрый выбор основных сервисов и единая кнопка применения. Для Telegram нажмите «Подключить в Telegram» после запуска приложения. Правила Linux используют fail-open: если процесс остановится, трафик продолжит идти напрямую.

Если YouTube не открывается в конкретной сети, в разделе «Подключение» можно сменить профиль только для YouTube: «Стандарт», «Мягкий», «Альтернативный» или «Без QUIC». Последний вариант заставляет браузер перейти с QUIC на TCP для доменов YouTube. Кнопка «Проверить соединение» проверяет доступность сайта и превью; она не подтверждает воспроизведение самого видео. Выбранный профиль сохраняется при обновлении приложения. Настройки Discord и Telegram при переключении не меняются.

PrivetZapret обрабатывает только соединения выбранных сервисов. Он не меняет внешний IP или страну аккаунта, поэтому региональные ограничения самого сервиса остаются без изменений.

Интерфейс обеих версий повторяет светлый визуальный стиль главной страницы PrivetDNS и адаптируется под размер окна.

## Основа

В комплект включены [zapret2](https://github.com/bol-van/zapret2) 1.0.6 и headless-сборка [TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy) 1.11.2. Оба компонента распространяются по лицензии MIT; тексты лицензий устанавливаются вместе с программой. Исходник TG WS Proxy фиксирован на ревизии `307a384ab7f522e34bb1a045884d0bd90f40bee5`, а вспомогательные файлы собираются GitHub Actions перед сборкой PrivetZapret. Перед сборкой применяется небольшая открытая правка: локальный ключ передаётся не в аргументах процесса и не печатается в журнал.
