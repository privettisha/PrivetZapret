# PrivetZapret

Простой клиент для YouTube и Discord на Windows 10/11 и Arch Linux. Устанавливается одной кнопкой, запускается вместе с системой и не отправляет весь интернет через сторонний сервер.

## Windows 10/11

1. Скачайте `PrivetZapret-Windows-x64.exe`.
2. Запустите файл и подтвердите запрос Windows.
3. Нажмите «Установить».

После установки программу можно закрыть — системная служба продолжит работать. Удаление доступно в том же окне.

## Arch Linux

Нужны `nftables` и `systemd`:

```bash
sudo pacman -S nftables
chmod +x PrivetZapret-Arch-x64
sudo ./PrivetZapret-Arch-x64
```

Откроется локальная страница управления. После установки сервис будет запускаться автоматически.

## Режимы

- **Сбалансированный** — основной вариант.
- **Совместимый** — более мягкая обработка для нестабильных сетей.
- **Усиленный** — если основной режим не помог.

Программа работает только с доменами YouTube и Discord. Правила Linux используют fail-open: если процесс остановится, трафик продолжит идти напрямую.

## Основа

В комплект включён [zapret2](https://github.com/bol-van/zapret2) версии 1.0.6 под лицензией MIT. Текст лицензии находится рядом с установленными файлами.
