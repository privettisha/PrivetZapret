# PrivetZapret

Локальное приложение для выбранных сервисов на Windows 10/11 и Arch Linux. Устанавливается одной кнопкой, запускается вместе с системой и не отправляет весь интернет через сторонний сервер.

## Windows 10/11

1. Скачайте `PrivetZapret-Windows-x64.exe`.
2. Запустите файл и подтвердите запрос Windows.
3. Нажмите «Установить».

После установки программу можно закрыть — системная служба продолжит работать. Удаление доступно в том же окне.

Для Telegram нажмите «Подключить в Telegram» и подтвердите добавление локального прокси. Программа поднимает его только на `127.0.0.1`, поэтому подключиться к нему извне нельзя.

Начиная с версии 0.2 WinDivert хранится в отдельной версионной папке: обновление не пытается перезаписать уже загруженный драйвер. Поэтому повторная установка работает даже когда Windows удерживает `WinDivert64.sys` в ядре и в диспетчере задач нет связанного процесса.

## Arch Linux

Нужны `nftables` и `systemd`:

```bash
sudo pacman -S nftables
chmod +x PrivetZapret-Arch-x64
sudo ./PrivetZapret-Arch-x64
```

Откроется локальная страница управления. После установки сервис будет запускаться автоматически.

В приложении можно выбрать YouTube, Discord, Telegram Desktop и сервисы из каталога мессенджеров, игр, социальных сетей и медиа. Есть поиск, быстрый выбор основных сервисов и единая кнопка применения. Для Telegram нажмите «Подключить в Telegram» после запуска приложения. Правила Linux используют fail-open: если процесс остановится, трафик продолжит идти напрямую.

Если выбранный сервис не открывается в конкретной сети, можно сменить его профиль или нажать «Подобрать». Для YouTube подбор теперь требует ответа не только от сайта, но и от видеосервера `googlevideo.com`; для SoundCloud проверяет доступность медиа-CDN. Проверка соединения не подтверждает воспроизведение конкретного видео или трека, голосовой чат либо вход в игру. Для YouTube есть отдельный вариант «Без QUIC»: браузер пробует соединение по TCP. Настройки остальных сервисов при переключении не меняются.

В настройках доступны свои домены и исключения, экспериментальный автосписок доменов, игровой режим и необязательное автообновление. Выученные автосписком домены теперь обрабатываются как по TCP, так и по QUIC без глобального перехвата UDP/443. Игровой режим включается только при выборе игры и обрабатывает характерные UDP-порты; он не гарантирует подключение к игровым серверам. В разделе «Проверка» находятся диагностика, восстановление службы, обновление одной кнопкой и откат. Обновление сохраняет режим, выбранные сервисы и ключ Telegram. Отчёт для поддержки не содержит ключ Telegram, свои домены и содержимое трафика. Для Windows и Linux есть меню в системном трее для быстрого запуска, остановки и выбора основных сервисов; его отображение зависит от поддержки трея окружением рабочего стола.

PrivetZapret обрабатывает только соединения выбранных сервисов. Он не меняет внешний IP или страну аккаунта, поэтому региональные ограничения самого сервиса остаются без изменений.

Интерфейс обеих версий повторяет светлый визуальный стиль главной страницы PrivetDNS и адаптируется под размер окна.

## Основа

В комплект включены [zapret2](https://github.com/bol-van/zapret2) 1.0.7 и headless-сборка [TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy) 1.11.2. Оба компонента распространяются по лицензии MIT; тексты лицензий устанавливаются вместе с программой. Исходник TG WS Proxy фиксирован на ревизии `307a384ab7f522e34bb1a045884d0bd90f40bee5`, а вспомогательные файлы собираются GitHub Actions перед сборкой PrivetZapret. Перед сборкой применяется небольшая открытая правка: локальный ключ передаётся не в аргументах процесса и не печатается в журнал. Меню трея использует [Go systray](https://github.com/gogpu/systray) (MIT).
