# PrivetZapret

Локальное приложение для выбранных сервисов на Windows 10/11 и Arch Linux. Устанавливается одной кнопкой, запускается вместе с системой и не отправляет весь интернет через сторонний сервер.

## Windows 10/11

1. Скачайте `PrivetZapret-Windows-x64.exe`.
2. Запустите файл и подтвердите запрос Windows.
3. Нажмите «Установить».

После установки программу можно закрыть — системная служба продолжит работать. Кнопка «Остановить» останавливает службу и оставшиеся процессы PrivetZapret, а также выключает её автозапуск до следующего нажатия «Запустить»; удаление доступно в том же окне.

Для Telegram кнопка «Подключить в Telegram» находится в верхнем блоке. Сервер, порт и секрет MTProto показаны там же и копируются отдельно для ручного добавления. Программа поднимает прокси только на `127.0.0.1`, поэтому подключиться к нему извне нельзя.

Для медиа Telegram встроенный помощник направляет напрямую только DC4; DC2 использует собственный маршрут с резервным Cloudflare-прокси. Это соответствует рекомендации автора TG WS Proxy для случаев, когда фото и видео не загружаются у аккаунтов без Premium. Домены резервного прокси включены в локальные правила PrivetZapret. Доступность конкретного маршрута всё равно зависит от сети пользователя.

Начиная с версии 0.2 WinDivert хранится в отдельной версионной папке: обновление не пытается перезаписать уже загруженный драйвер. Поэтому повторная установка работает даже когда Windows удерживает `WinDivert64.sys` в ядре и в диспетчере задач нет связанного процесса.

## Arch Linux

Нужны `nftables` и `systemd`:

```bash
sudo pacman -S nftables
chmod +x PrivetZapret-Arch-x64
sudo ./PrivetZapret-Arch-x64
```

Откроется локальная страница управления. После установки сервис будет запускаться автоматически.

В приложении можно выбрать YouTube, Discord, Telegram Desktop и сервисы из каталога мессенджеров, игр, социальных сетей и медиа. Есть поиск, быстрый выбор основных сервисов и единая кнопка применения. Для Telegram нажмите «Подключить в Telegram» после запуска приложения. Правила Linux используют fail-open: если процесс остановится, трафик продолжит идти напрямую.

Если выбранный сервис не открывается в конкретной сети, можно сменить его профиль или нажать «Подобрать». Для YouTube подбор требует ответа не только от сайта, но и от видеосервера `googlevideo.com`; для SoundCloud проверяет доступность медиа-CDN. Известные медиадомены YouTube и Discord переходят на TCP, если QUIC мешает воспроизведению. Проверка соединения не подтверждает воспроизведение конкретного видео или трека, голосовой чат либо вход в игру. Для YouTube есть отдельный вариант «Без QUIC»: браузер пробует соединение по TCP. Настройки остальных сервисов при переключении не меняются.

В настройках доступны свои домены и исключения, автоподбор заблокированных доменов, игровой режим и необязательное автообновление. Автоподбор включён по умолчанию, следит за ошибками TCP и QUIC и запоминает адреса независимых медиасерверов; его можно выключить. Он не гарантирует доступ к потокам, которые используют скрытые адреса, шифруют имя сервера или требуют IP другой страны. Игровой режим включается только при выборе игры и обрабатывает характерные UDP-порты; он не гарантирует подключение к игровым серверам. В разделе «Проверка» находятся диагностика, восстановление службы, обновление одной кнопкой и откат. Обновление сохраняет режим, выбранные сервисы и ключ Telegram. Отчёт для поддержки не содержит ключ Telegram, личную DoH-ссылку, свои домены и содержимое трафика. Для Windows и Linux есть меню в системном трее для быстрого запуска, остановки и выбора основных сервисов; его отображение зависит от поддержки трея окружением рабочего стола.

На Windows 10 версии 2004 и новее, а также Windows 11, в разделе «Свой DoH» можно вставить HTTPS-ссылку любого DNS-over-HTTPS сервера и включить его для системного DNS. Приложение проверяет сервер до изменения настроек, сохраняет исходные DNS основного Wi-Fi или Ethernet адаптера и восстанавливает их при остановке или удалении. Локальный DNS-посредник обслуживает UDP/TCP 53 на 127.0.0.1 и ::1. Если DoH временно не отвечает, запросы направляются на прежние DNS-серверы подключения (без шифрования). Для работы нужен свободный локальный порт 53; VPN и другое DNS-приложение на основном адаптере должны быть отключены. Браузеры с собственным DNS могут обходить системную настройку. В версии для Arch Linux системный DoH пока недоступен.

PrivetZapret обрабатывает соединения выбранных сервисов и адреса, добавленные автоподбором. Он не меняет внешний IP или страну аккаунта, поэтому региональные ограничения самого сервиса остаются без изменений.

Интерфейс обеих версий повторяет светлый визуальный стиль главной страницы PrivetDNS и адаптируется под размер окна.

## Основа

В комплект включены [zapret2](https://github.com/bol-van/zapret2) 1.0.7 и headless-сборка [TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy) 1.11.2. Оба компонента распространяются по лицензии MIT; тексты лицензий устанавливаются вместе с программой. Исходник TG WS Proxy фиксирован на ревизии `307a384ab7f522e34bb1a045884d0bd90f40bee5`, а вспомогательные файлы собираются GitHub Actions перед сборкой PrivetZapret. Перед сборкой применяется небольшая открытая правка: локальный ключ передаётся не в аргументах процесса и не печатается в журнал. Меню трея использует [Go systray](https://github.com/gogpu/systray) (MIT).
